# Project Ether (灵质) - 2D Action RPG Prototype

`Project Ether` 是一款基于 **Godot 4** 开发的 2D 顶视角多人动作 RPG 游戏系统原型。
本项目灵感来源于动画《罗小黑战记》中的虚拟现实游戏《众生之门》，旨在通过 AI 协作（Codex-Driven）的方式，探索高精度即时动作战斗、局域网权威同步架构以及数值可视化系统的开发。

## 🚀 核心技术栈 (Technical Stack)

- **游戏引擎 (Engine)**: Godot 4.x (GDScript)
- **网络架构 (Networking)**: Godot 高层 Multiplayer API (ENet)
- **同步模型 (Sync Model)**: 房主权威服务器模式 (Server-Authoritative Listen-Server)
- **核心算法 (Combat Core)**: 实时 2D 几何向量点积计算（用于实现无视等级的“要害判定/背击”机制）

## 🗺️ 项目迭代规划 (Roadmap)

### 📌 Phase 1: 基础设施与数据可视化（当前阶段）
- [ ] **局域网大厅**: 实现本地多实例（Multi-Instance）一键开房与加入。
- [ ] **全息启动界面**: 还原动画风格的登录与角色创建（六大系别选择）。
- [ ] **RPG 数值底座**: 建立玩家属性面板、经验升级公式，支持局域网状态实时同步。
- [ ] **JSON 技能树**: 动态加载的有向无环图（DAG）技能解锁系统。

### 📌 Phase 2: 即时动作与高精度判定（下一阶段）
- [ ] **8方向移动控制器**: 包含带无敌帧的翻滚与动态朝向向量（Facing Radians）。
- [ ] **无头物理验证**: 房主端权威计算攻击判定框（Hitbox）。
- [ ] **要害判定系统**: 基于攻击向量与目标朝向夹角的计算，实现“无视防御/等级差”的致命背击伤害。

## 💻 开发者指南 (For Developers / macOS)

### 开发环境准备
1. 下载并安装 [Godot 4.x (Standard Version)](https://godotengine.org/).
2. 推荐使用 **Cursor** 或 **VS Code (配合 GDScript 插件)** 作为外部代码编辑器。

### 本地多人联机调试 (Mac 特异功能)
为了在单台 Mac 上测试局域网联机，请在 Godot 编辑器中配置：
1. 点击顶部菜单 `调试 (Debug)` -> `运行多个实例 (Run Multiple Instances)`。
2. 选择设置实例数量为 `2`。
3. 点击运行，系统会同时弹出一个房主窗口（Host）和一个客户端窗口（Join），即可在本地直接调试网络同步。
